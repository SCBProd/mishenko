ЩО ВСЕРЕДИНІ
• dist/ — готовий сайт: HTML, CSS, JavaScript, зображення та документи.
• src/, build-cinema.cjs, JSON і допоміжні скрипти — вихідні файли.
• document-source/ — джерела для документів CV і творчого шляху.
• archived-artworks/ — архів вилучених робіт, не публікується як частина dist.
• .openai/hosting.json — конфігурація чинного хостингу, не секретний ключ.
Історія Git, тимчасові файли й облікові дані не включені.
Розділу «Ескізи і проєкти» в цій версії ще немає.

ЛОКАЛЬНИЙ ПЕРЕГЛЯД
Розпакуйте архів на SSD. Відкрийте термінал у папці Krystyna-Mishchenko-Site.
Якщо встановлено Python, виконайте:
  python -m http.server 8000 --directory dist
На Windows також можна використовувати:
  py -m http.server 8000 --directory dist
Відкрийте http://localhost:8000 у браузері.
Команда працює, доки відкритий термінал; зупинка — Ctrl+C.
Можна використати будь-який інший локальний статичний вебсервер.
Для зовнішніх посилань та ресурсів може знадобитися інтернет.

ПЕРЕНЕСЕННЯ НА ХОСТИНГ
Завантажуйте вміст папки dist у корінь статичного хостингу.
Не потрібно завантажувати archived-artworks або document-source.
Готова версія не потребує Node.js, Next.js, Vue, Vite або бази даних на сервері.

РЕДАГУВАННЯ
Перед змінами збережіть копію архіву.
Для повторного запуску власного генератора сторінок потрібен Node.js:
  node build-cinema.cjs
Запускайте з кореня проєкту. Генератор змінює файли у dist.
Не запускайте всі допоміжні скрипти поспіль: деякі створені для разових правок.
Для розгортання на іншому сервісі користуйтеся його налаштуваннями;
зміна цих локальних файлів сама по собі не змінює опублікований сайт.
