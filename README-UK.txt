ПОРТФОЛІО KRYSTYNA MISHCHENKO — СТАТИЧНИЙ САЙТ

## Запуск локально

Сайт — це HTML, CSS і JavaScript без Next.js та npm-залежностей. Для створення копії для публікації потрібен Node.js.

```sh
node scripts/prepare-legacy.mjs
python -m http.server 8000 --directory public/legacy
```

Відкрийте http://localhost:8000.

## Публікація на GitHub Pages

Для цього варіанта сайт публікується на GitHub Pages зі статичної копії в `public/legacy/`.

У налаштуваннях репозиторію відкрийте Settings → Pages і встановіть Source: GitHub Actions. Workflow `.github/workflows/pages.yml` публікує сайт після змін у `main`.

## Де редагувати

- `dist/` — вихідні файли сторінок, стилів, сценаріїв, зображень і документів портфоліо.
- `src/`, `document-source/` та JSON-файли в корені — вихідні дані й генератори окремих матеріалів.
- `scripts/prepare-legacy.mjs` — підготовка runtime-копії та правила для верхньої плашки.
- `public/legacy/` — згенерована статична копія для локального перегляду й публікації; вручну її не редагуйте.
- `archived-artworks/` — архів робіт; він не входить до сайту.

Зберігайте `dist/`, вихідні матеріали та архів робіт: сайт і подальше редагування залежать від цих файлів. Музей та нічна експозиція залишаються поза runtime; хаб містить кераміку, фотографію та 3D-мистецтво.
